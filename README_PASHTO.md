# Farid AI Video — د Android پروژې لومړنۍ نسخه

دا د Android Studio لپاره د Kotlin + Jetpack Compose پروژه ده.

## اوس څه کار کوي؟
- عصري ارغواني/آبي ډیزاین
- د پښتو، دري، عربي او انګلیسي ژبې انتخاب
- د Text to Video د متن داخلولو سکرین
- د Image to Video، Voice to Video او Lip Sync د فیچرونو ښکاره کارتونه

## څه لا نه دي نښلول شوي؟
دا لا بشپړ AI ویډیو جوړوونکی نه دی. د حقیقي ویډیو تولید لپاره باید یو AI خدمت یا خپل سرور/API ورسره ونښلول شي. د غږ ثبتول/اپلوډ، د عکس انتخاب، Lip Sync، ویډیو ذخیره او ډاونلوډ هم باید د راتلونکو پړاوونو کې پلي شي. د نامحدود او بشپړ وړیا تولید ژمنه ممکنه نه ده، ځکه AI ویډیو تولید سرور او GPU لګښت لري.

## APK څنګه جوړ کړې؟
1. Android Studio نصب کړه.
2. دا پروژه په Android Studio کې خلاصه کړه.
3. د Gradle Sync بشپړېدو ته انتظار وباسه.
4. له Build > Build Bundle(s) / APK(s) > Build APK(s) څخه APK جوړ کړه.

## تخنیکي اړتیا
- Android Studio (اوسنۍ نسخه)
- JDK 17
- Android SDK 35
